목적
Spring의 복수 반복 요일을 Nest 일정 요일 행으로 손실 없이 이관하고, 이미 발생한 단일-요일 오이관을 안전하게 탐지·복구한다.
사용자
레거시 Spring DB를 Nest 호환 스키마로 전환하는 개발·운영 담당자

목표와 비목표

주간 일정의 요일은 시작일에서 추론하지 않고, 유효한 레거시 관계의 모든 period.days에서만 복사한다.

비목표: Spring 원본 데이터 자체를 정정하거나, 유효 기간·실행 기록·일정 편집 이력을 새로 해석하지 않는다.

변경 모델

  1. DDL과 별개로 원본·대상 무결성을 읽기 전용 사전검사한다.
  2. 검사가 통과한 경우에만 하나의 트랜잭션에서 일정 행과 모든 요일 행을 쓴다.
  3. 커밋 전, 각 주간 일정의 대상 요일 집합이 원본 집합과 동등한지 다시 확인한다.

불변식과 사전검사

실패하면 쓰기 전 중단해야 하는 조건
검사조건이유와 처리
고아 연결jogak_period.jogak_id 또는 period_id가 참조 대상을 찾지 못함복사할 정본이 불명확하다. ID와 건수를 보고하고 중단한다.
요일 값period.days가 정확히 MONDAY…SUNDAY 중 하나가 아님대상 enum 계약을 위반한다. 대소문자 변환·trim으로 묵인하지 않고 중단한다.
주간 원본 누락is_routine = true Jogak에 유효한 원본 요일이 0개빈 WEEKLY는 Nest 정책상 불가하다. 시작일 요일로 보정하지 않는다.
원본 중복동일 jogak_id + days가 둘 이상관계 중복을 명시적으로 보고한다. 기본 모드는 중단한다.
대상 충돌Jogak당 호환 일정이 둘 이상이거나, 대상에 원본과 다른 요일 집합이 이미 있음기존 Nest 편집인지 과거 오이관인지 자동 판별할 수 없다. 기본 모드는 중단한다.
핵심 불변식: WEEKLY 일정마다 target_weekdays = DISTINCT(valid period.days joined via jogak_period) 이다. ONCE에는 요일 행이 0개여야 한다.

신규 백필과 과거 오이관 복구

기본 모드는 대상 일정이 없는 Jogak만 생성한다. 생성된 주간 일정에는 INSERT … SELECT DISTINCT jp.jogak_id, p.days로 모든 요일을 넣는다. 기존 단일 행이 있으면 건드리지 않고 충돌로 실패한다.

명시적 복구 모드는 별도 플래그(예: --repair-weekdays)와 사전 백업/리포트가 있을 때만 사용한다. 원본과 다른 대상 요일 집합을 가진 레거시 호환 일정을 대상으로, 해당 일정의 요일 행을 원자적으로 원본 집합으로 교체한다. 이 모드는 Nest에서 일정 수정이 시작되기 전 또는 변경 대상 ID가 승인된 경우에만 실행한다.

복구 대상·원본 집합·기존 대상 집합·삭제/삽입 예정 건수를 커밋 전에 출력한다. 검증 쿼리에서 차이가 한 건이라도 남으면 예외를 던져 전체 트랜잭션을 롤백한다.

결정 기록

결정
시작일 요일 추론을 제거하고, 원본 관계 JOIN만으로 요일을 이관한다.
근거·가정
Spring 생성 로직이 요청의 모든 days를 Period 관계로 저장한다. 전환 시점에는 그 관계가 정본이라고 가정한다.
가장 강한 반증 또는 완화
이미 Nest에서 편집한 일정은 레거시와 다를 수 있다. 그래서 기본 모드는 기존 대상과의 불일치를 자동 덮어쓰지 않고, 별도 복구 모드와 승인된 대상 목록을 요구한다.
미룬 범위·재검토 조건
새 스키마의 DB CHECK/FK 강화는 별도 변경으로 미룬다. 레거시 테이블 제거 전까지 대상과 원본의 이중 쓰기가 필요해지면 정본 선택을 재승인한다.

검증 계획

  1. 사전검사 SQL을 실제 운영 DB에서 읽기 전용으로 실행하고, 고아·잘못된 값·빈 주간·중복·대상 충돌이 0인지 확인한다.
  2. 테스트 DB에 월·수, 일요일, 단일 요일, 비반복 Jogak 및 각 오류 표본을 만든다.
  3. 기본 모드 실행 후 월·수는 정확히 두 행, 일요일은 SUNDAY, 비반복은 0행인지 확인한다.
  4. 과거 단일-요일 오이관 표본에서 기본 모드는 중단하고, 승인된 복구 모드만 정확한 집합으로 교체하는지 확인한다.
  5. 실패 표본마다 대상 테이블 변경이 0건인지, 성공 표본마다 원본·대상 집합 차이가 0건인지 확인한다.
