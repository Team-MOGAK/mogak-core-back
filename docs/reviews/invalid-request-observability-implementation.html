현재 구현

GlobalExceptionFilter가 모든 Z005의 원문 params/query/body를 기록한다. authorization, token, password, secret, cookie를 포함하는 중첩 키는 키와 값 모두 제거하고, multipart body도 기록하지 않는다. 깊이·배열·객체·문자열 크기 제한은 [TRUNCATED]다.

구현 상태

src/common/domain.exception.ts는 공통 도메인 예외로 유지하고, src/common/http/globalException.filter.ts에서 blacklist 기반 정제를 구현했다. Zod pipe는 원래의 Z005 변환 책임만 가진다. 독립 읽기 전용 점검에서 승인 범위의 blocker 없음으로 확인됐다.

이슈 등록부

완화됨: allowlist가 새 비민감 입력을 누락하던 설계를 제거했다. 승인된 인증 키는 재귀적으로 로그에서 제거하고, 대소문자·배열 헤더를 포함한 multipart 원문·과도한 payload는 별도 경계로 처리한다. 정제 중 접근 오류도 요청값을 생략해 Z005 응답을 유지한다. 현재 독립 점검 중이다.
