모각 조각 통합 조회 설계

설계 상태: 승인됨 · 구현 중 · 강도: compact

목표

모각 화면에서 날짜와 무관하게 조각 전체를 일정과 함께 볼 수 있게 하고, 기존 특정 날짜 회차 조회도 유지한다.

제안 동작

  • GET /api/mogaks/{mogakId}/jogaks: 모각 소속 전체 조각을 반환한다.
  • GET /api/mogaks/{mogakId}/jogaks?date=YYYY-MM-DD: 해당 날짜의 회차만 반환한다.

두 경우 모두 동일한 조각 응답 필드를 쓴다. 전체 조회에서는 scheduledDate, status를 null로 둔다. 날짜 조회에서는 회차 날짜와 진행 상태를 채운다. 조각 제목은 항상 현재 제목이다. 일정 필드(isRoutine, days, startDate, endDate)와 기존 조각 표시 정보는 유지한다.

{
  "jogakId": 101,
  "title": "포트폴리오 정리",
  "isRoutine": true,
  "days": ["MONDAY", "WEDNESDAY", "FRIDAY"],
  "startDate": "2026-10-01",
  "endDate": null,
  "scheduledDate": null,
  "status": null
}

범위와 불변 조건

  • 날짜 없는 조회는 일정 기간과 무관하게 모각에 속한 조각 전체를 반환한다.
  • 날짜가 있으면 기존 날짜별 포함/상태 판정 규칙을 유지한다.
  • 양쪽 응답의 필드 구조와 조각 제목 기준을 동일하게 한다.
  • 실행 기록에 저장된 제목 스냅샷과 DB 필드는 보존하고, 조회 응답에서 현재 조각 제목을 사용한다.

검증 계획

전체 조회에 미래 일정 및 종료된 루틴이 포함되는지, 날짜 조회가 기존 날짜별 상태를 유지하면서 현재 제목을 내는지, 잘못된 날짜와 권한 없는 모각이 기존 오류 응답을 내는지 확인한다.

설계 이해 점검

날짜 없이 조회하면 날짜별 진행 상태는 어떻게 표현할까?

승인

2026-11-02 승인. 승인 범위: 같은 경로에서 date 유무에 따라 전체 조각 또는 날짜별 조각을 조회하며, 응답 모양은 통일하고 제목은 현재 값으로 반환한다. 스냅샷 저장 데이터 삭제는 포함하지 않는다.
