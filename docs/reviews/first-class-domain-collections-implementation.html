승인 기준

JogakWeekdays는 Routine 전용의 유효한 요일 집합이다. OnceSchedule과 RoutineSchedule은 발생 규칙을 각각 소유하고, JogakSchedules는 순수 일정 이력의 활성·최신·후속 선택을 소유한다. API·DB·repository 계약 및 날짜별 발생/실행 경계는 유지한다.

현재 구현

JogakWeekdays, OnceSchedule, RoutineSchedule, JogakSchedules를 추가했다. service는 persistence row를 fail-fast rehydrate하고 발생·대표·수정 대상/후속 선택을 domain 행위로 수행한다. repository/API에는 기존 배열 DTO만 전달한다.

구현 상태

구현 완료 — 활성 Routine 우선 상세 선택, Once 정확한 날짜 선택, Routine 기간·요일 발생, 후속 경계 보존을 반영했다.

잔여 위험

활성 Routine과 과거 Once가 함께 있으면 설정 상세는 활성 Routine을 대표로 선택한다. repository/API로 클래스 인스턴스가 누출되지 않도록 snapshot/배열 경계를 유지했다.
