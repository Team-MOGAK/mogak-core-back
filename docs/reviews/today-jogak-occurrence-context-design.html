오늘 조각 회차의 모각 정보 제공 설계

설계 상태: 승인됨 · 구현 완료 · 강도: compact

목적 지문

목적
오늘 조각 목록에서 루틴 요일과 출처 모다라트 정보를 한 번의 목록 조회로 제공한다.
사용자
오늘 화면을 보는 앱 사용자
문제
조각별 상세 요청 때문에 요일과 모다라트 제목을 목록에서 표시하기 어렵다.
핵심 흐름
날짜 회차 조회 → 회차 응답으로 화면 행과 모다라트 제목 구성

제안 계약

기존 회차 응답 필드를 유지하면서 GET /api/jogaks?date=와 GET /api/mogaks/{mogakId}/jogaks?date=의 각 항목에 mogakId, modaratId, days를 추가한다. `days`는 루틴 요일 목록이며 일회성 조각은 빈 배열이다. 모각 경로에서는 해당 경로의 모각 ID와 일치한다.

{
  "jogakId": 101,
  "scheduledDate": "2026-11-02",
  "mogakId": 12,
  "modaratId": 3,
  "days": ["MONDAY", "WEDNESDAY", "FRIDAY"]
}

구현 범위와 불변 조건

  • 두 날짜별 조회의 항목에 세 필드를 추가한다.
  • 기존 응답 필드, 회차 포함 조건, 진행 상태 계산, 인증·소유권 검사는 유지한다.
  • 모다라트 ID는 현재 조각이 속한 모각의 부모 ID를 반환한다.
  • 날짜 조회가 아닌 전체 조각 조회는 이번 변경 대상이 아니다.

검증 계획

두 조회 경로에서 ID와 요일이 정확한지, 일회성 조각 요일이 빈 배열인지, 기존 응답 필드와 날짜별 상태가 유지되는지 확인한다.

설계 이해 점검

모각별 날짜 회차 경로에서 반환할 mogakId는 무엇이어야 할까?

승인 및 구현 기록

2026-11-02 사용자 승인. 승인 범위: 두 날짜별 회차 조회 항목에 mogakId·modaratId·days를 추가하고 기존 응답과 동작을 유지한다. 구현: schedule row에서 mogakId와 modaratId 전달, 두 회차 조회 결과에 두 ID와 days 포함. 전체 조각 조회도 공통 항목 구조를 유지하도록 두 ID 포함.

검증 증거

pnpm typecheck 통과. 조각 서비스 및 컨트롤러 관련 테스트 실행 중 확인된 기존 fixture에 modaratId를 추가하고, 날짜 회차 응답에서 mogakId·modaratId·days를 확인하도록 보강했다. 최종 관련 테스트와 포맷 검증 결과를 확인한다.
