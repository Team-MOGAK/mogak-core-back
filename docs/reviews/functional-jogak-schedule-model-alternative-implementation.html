조각 일정 함수형 모델 구현 제어

목적
조각 일정 규칙을 순수 함수와 discriminated union으로 유지하며 런타임 클래스를 제거한다.
사용자
Jogak 일정 기능을 유지보수하는 백엔드 개발자와 API 사용자.
문제
일정 row를 클래스 객체로 재구성한 후 plain DTO로 되돌리는 중간 할당과 복잡도가 있다.
핵심 흐름
요청/영속 row → 검증된 plain schedule → 순수 발생·선택 함수 → 기존 배열 DTO.

승인 기준

ONCE/WEEKLY discriminated union, weekday 검증·복사, 발생·대표·후속 선택 순수 함수로 바꾼다. API·DB·repository DTO와 선택·오류 의미는 유지한다.

현재 구현

ValidatedJogakSchedule을 ONCE/WEEKLY discriminated union으로 바꾸고, 생성·요일 검증·발생·이력 선택을 순수 함수로 옮겼다. service는 plain schedule을 직접 사용하며 runtime class, instanceof, toSnapshot(), identity 기반 재탐색을 제거했다.

구현 완료 — API·DB·repository DTO와 대표·수정·후속 선택 및 persistence 오류 의미를 유지했다.
