기준과 실제 구현

  • 주간 API의 요청일이 포함된 서울 기준 일요일~토요일 집계와 기존 응답 계약을 유지한다.
  • weekContaining가 계산한 경계의 UTC 연도가 0001~9999인지 확인한다. 범위를 벗어나면 DomainErrorCode.INVALID_TARGET_DATE를 던져 HTTP 400을 반환한다.
  • 주간 경계를 계산한 뒤 소유권 조회 전에 거부하므로, 범위 밖 날짜는 추가 집계 쿼리를 실행하지 않는다. 정상 날짜의 기존 소유권·집계 흐름은 유지한다.
  • 수정 파일: libs/core/src/core/mogaks/application/service/mogak.service.ts, test/mogaks/application/mogak.service.spec.ts, test/mogaks/presentation/modaratMogak.controller.spec.ts.
