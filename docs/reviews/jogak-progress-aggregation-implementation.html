B-1 진척 집계 구현 기록

implementation-control-state: 구현 완료 · branch codex/b12-occurrence-context

구현 내용

  • GET /api/modarats/{modaratId}/progress?date=에서 요청일이 포함된 서울 기준 일요일~토요일 주간을 계산한다.
  • 모다라트 전체와 모든 하위 모각의 planned/done/percent를 반환하고, 회차가 없는 모각은 0으로 포함한다.
  • 계획 일정과 실행 행을 (jogakId, scheduledDate)로 합쳐 중복을 막는다. 일정에 없는 실행 행은 start-added 회차로 집계한다.
  • 날짜 검증, 인증, 모다라트 소유권 확인을 유지한다.

검증

pnpm typecheck, pnpm lint, pnpm build 통과. pnpm test --runInBand test/mogaks/application/mogak.service.spec.ts test/mogaks/presentation/modaratMogak.controller.spec.ts 통과: 2 suites, 23 tests.

이슈 및 잔여 위험

해결: 비일정 실행에는 일정 행이 없어 처음에는 모각을 판별할 수 없었다. 소유 모다라트의 조각-모각 관계를 조회해 올바른 하위 집계에 배정하도록 보완했다.

잔여 위험: B-13에서 실행을 다른 저장 경로로 옮기면 B-1의 비일정 실행 조회도 그 저장 경로를 반영해야 한다. 현재 저장소의 실행 행을 읽는 구현에서는 이 위험이 발생하지 않는다.

구현 이해 상태
