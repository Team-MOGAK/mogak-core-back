구현 준비

승인 기준선

Modarat·Mogak은 PATCH로 즉시 전환한다. canonical application/merge-patch+json만 허용한다. 공통 decorator/guard/interceptor가 media type과 Accept-Patch를 처리하며, 이전 PUT은 tombstone으로 405 및 Allow: PATCH를 반환한다. Jogak·marketing-consent도 같은 media type 정책을 적용한다.

현재 구현

@MergePatch() 복합 decorator·공통 Content-Type guard·응답 interceptor를 추가했다. Modarat·Mogak 수정은 PATCH로 전환해 생략 필드를 보존하며, Jogak·marketing-consent도 canonical media type 정책을 사용한다. 중앙 retired-PUT middleware는 Modarat·Mogak에만 405·Allow: PATCH를 반환한다. CORS는 tombstone보다 먼저 적용한다.
