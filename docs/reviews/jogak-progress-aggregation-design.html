B-1 진척 집계 API 설계

설계 상태: 구현 완료 · 승인됨 · 강도: compact · 작업 브랜치: codex/b12-occurrence-context

목표와 범위

판·모다라트 전환 화면에서 이번 주 진척을 한 번의 요청으로 표시하고, 주간 달력과 마이페이지는 선택 기능으로 남긴다. 기존 DB 모델을 재사용하며 새 저장 테이블은 만들지 않는다.

필수 계약

GET /api/modarats/{modaratId}/progress?date=YYYY-MM-DD. 입력 날짜가 속한 서울 시간대 주간(일요일~토요일)을 집계한다. 미래 날짜 회차도 분모에 넣는다.

{
  "result": {
    "weekStart": "2026-10-25",
    "percent": 36,
    "doneCount": 9,
    "plannedCount": 25,
    "mogaks": [
      { "mogakId": 12, "percent": 33, "doneCount": 2, "plannedCount": 6 }
    ]
  }
}
  • 모다라트 전체 합계와 그 안의 모각별 집계를 함께 반환한다. 회차가 없는 모각도 0으로 포함한다.
  • plannedCount는 해당 주의 루틴 회차와 start로 그날 추가한 회차의 수다.
  • doneCount는 계획 회차 중 SUCCESS 수다. percent는 done/planned의 정수 반올림이며 planned가 0이면 0이다.
  • 중복 방지 기준은 조각과 예정일의 조합(jogakId, scheduledDate)이다. 요일 테이블 조인 행 수를 그대로 회차 수로 세지 않는다.
  • B-13 실행 API 자체의 설계·수정은 이 범위에 포함하지 않는다. 다만 B-13에서 만든 그날의 회차를 조회 가능한 회차 데이터로 제공해야 이 집계에 포함할 수 있다. 이 데이터 연결은 구현 전 확인할 의존성이다.

선택 기능 — 이번 구현에서는 보류

  • GET /api/jogaks/summary?from=&to=: 달력용 날짜별 집계, 최대 42일.
  • GET /api/users/stats: 누적 totalDoneCount.

주요 경계와 검증

서울 기준 일요일 시작·토요일 종료, 주 시작/끝 날짜 경계, 미래 계획 회차 분모 포함, 같은 날 start 회차 포함, 요일 조인으로 인한 중복 미계수, 미완료·실패는 분모에만 포함, 빈 주 및 회차 없는 모각의 0 처리, 모다라트 소유권 검사를 검증한다.

설계 이해 점검

목요일이 요청 날짜라면 미래 토요일 계획 회차는 무엇에 반영될까?
