워크트리 통합 테스트 격리 설계

목적: 어느 Git 워크트리에서도 pnpm test:integration --runInBand가 다른 작업 디렉터리나 개발 DB를 건드리지 않고 재현 가능하게 실행되게 한다.

현재 관찰

jest.db.config.ts가 일반 DATABASE_URL을 읽어 DB 이름만 mogak_test로 바꾼다. 별도 테스트 연결을 명시할 수 없고, 동일 DB를 모든 워크트리가 공유한다.

Jest는 루트 전체를 탐색한다. 루트 아래의 다른 저장소 사본(refactor/)도 발견해 haste 충돌과 TypeScript 전역 선언 중복을 낸다. 현재의 .worktrees/ 예외는 그 경로 밖 사본을 막지 못한다.

migration 실패는 테스트 본문 전에 발생한다. Drizzle의 상위 오류만으로는 DB 연결 불가와 스키마 권한 오류를 구분할 수 없으므로, 실제 PostgreSQL 연결 상태를 먼저 확인해야 한다.

확정 설계: 단일 테스트 DB의 안전한 재사용

  1. Jest의 roots를 apps/api/src와 test로 제한한다. 중첩 저장소/워크트리 이름에 의존하지 않는다.
  2. 기존처럼 개발 DB URL에서 mogak_test를 유도한다. DB 이름이 _test로 끝나는 안전 장치는 유지한다.
  3. Compose 초기화 스크립트는 기존처럼 mogak_test를 생성한다. DB 테스트를 실행하기 전 PostgreSQL이 .env의 포트에서 실행 중이어야 한다.

새 환경 변수나 런타임 의존성 없이 기존 PostgreSQL/Compose 운영 방식을 유지한다. DB 통합 테스트를 동시에 실행하지 않는 현재 작업 방식에 맞춘다.

의도적으로 제외한 범위

워크트리별 TEST_DATABASE_URL과 Testcontainers는 도입하지 않는다. 여러 워크트리에서 DB 테스트를 병렬 실행할 필요가 생길 때 별도 변경으로 검토한다.

추가 설계: Drizzle 스키마 정합 migration

새 관찰: DB 테스트가 실제 실행된 뒤, migration이 만든 users.id와 런타임 Drizzle 스키마가 요구하는 users.user_id의 불일치가 확인됐다. 테스트 DB를 비워도 기존 migration만으로는 현재 스키마가 만들어지지 않는다.

  1. mogak_test만 연결을 종료하고 drop/create한다. mogak_local과 다른 DB에는 쓰지 않는다.
  2. drizzle-kit push로 현재 runtime Drizzle schema를 빈 mogak_test에 적용한다.
  3. 테스트 DB bootstrap은 로컬 환경 준비 단계로 분리한다. test:integration은 준비된 테스트 DB에서 Jest만 실행한다.
  4. 통합 테스트를 실행해 준비된 schema와 런타임 schema의 정합을 검증한다.

제외: 운영/개발 migration 파일을 수정하거나 기존 DB schema를 rename하지 않는다. mogak_test 외 DB는 초기화하지 않는다.

변경 범위와 수용 기준

  • jest.config.ts, jest.db.config.ts, TypeScript/ESLint 설정, Compose 초기화, README 및 설정 테스트를 수정한다.
  • 루트에 임의의 중첩 프로젝트가 있어도 Jest 충돌 없이 DB 테스트를 수집한다.
  • Compose PostgreSQL이 실행 중일 때 mogak_test에서 migration을 적용할 수 있다.
  • 일반 DATABASE_URL가 _test가 아닌 DB를 가리킬 때 그 DB에는 쓰지 않는다.

구현 리뷰

실제 흐름: Jest·TypeScript·ESLint는 각각 소스와 테스트로 탐색 범위를 한정한다. DB 테스트는 기존처럼 mogak_test만 대상으로 migration을 적용하며, PostgreSQL이 지정 포트에서 실행 중이어야 한다.

검증 증거와 공백

  • pnpm typecheck, pnpm lint, pnpm format:check 통과.
  • 일반 Jest 및 DB Jest의 --listTests에서 루트 refactor/가 수집되지 않음을 확인.
  • 실제 test:integration --runInBand는 migration 상위 오류로 중단됐다. 5432·5436·15432 포트가 모두 연결 거부여서 PostgreSQL 기동 후 최종 재검증이 필요하다.
리뷰 판단: 테스트 DB bootstrap 변경의 승인과 검증이 필요하다. 운영/개발 DB migration 정합은 별도 후속 과제다.
